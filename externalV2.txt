# MyOS external.txt — apt 기본 repo 밖에서 설치하는 것
# [auto]   = bootstrap에서 자동
# [manual] = USB에서 직접 복사

# ===== 3rd-party apt repo [auto] =====
# codename은 하드코딩 금지: $(. /etc/os-release; echo $VERSION_CODENAME)

# Brave
#   curl -fsS https://dl.brave.com/install.sh | sh
# Tailscale
#   curl -fsSL https://tailscale.com/install.sh | sh
# Docker
#   docker.com repo (codename 자동) 후
#   apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
#   (group 추가는 servicesV2.txt에서 처리)
#   ※ resolute용 repo 있는지 VM에서 확인

# ===== 언어 toolchain [auto] =====
# Rust
#   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
#   cargo install tzupdate bluetui
#   (nightly 필요할 때만) rustup toolchain install nightly
# npm global
#   sudo npm i -g @termix-ssh/cli
# Python venv (COA 2: 호스트 전역 PyTorch venv 생략, 프로젝트별 on-demand uv/venv 사용)
#   ※ 필요 시 ~/myOs/requirements.txt 기준으로 개별 프로젝트에 설치

# ===== USB에서 복사 [manual] =====
# ~/.local/bin/agy                    (Antigravity CLI, 234MB)
# ~/.local/bin/clika-runtime-agent
# ~/.aigo/bin/*                       (aigo, aigo-server, AppImage, continuum-router)
# ~/workspace/platform-tools/arduino-ide_*.AppImage
# ~/workspace/platform-tools/arduino-cli
# ~/workspace/platform-tools/ArduinoAppLab_*/
# pdfcraft_0.9.0-1_amd64.deb          -> sudo apt install ./pdfcraft*.deb
# luit_*.deb                          -> sudo apt install ./luit*.deb
# ※ .old / .previous 백업 파일은 안 가져감
# ※ android platform-tools는 apt의 adb/fastboot로 대체
